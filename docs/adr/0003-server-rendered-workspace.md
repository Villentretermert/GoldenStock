# ADR-0003: серверные страницы рабочего кабинета
Дата: 2026-10-22. GS-006–008.

Кабинет рендерится Python/FastAPI, небольшой JavaScript отправляет формы в API того же origin. Это пересмотр кандидата NiceGUI после GS-005: для входа, списков и загрузок достаточно обычных HTTP-страниц; сессия и CSRF проверяются единообразно на каждой операции. Нет отдельного состояния прав в WebSocket callback. CSS и JavaScript локальные, пользовательские значения экранируются. NiceGUI пока остаётся в lock-файле совместимости, но runtime кабинета его не использует.

Изоляция организаций обеспечивается прикладными tenant/owner проверками всех доменных маршрутов и отрицательными API-тестами. PostgreSQL RLS из проектного документа остаётся дополнительным усилением, не реализованной защитой. До удалённого пилота GS-023 требуется проверить TLS/VPN, RLS/служебные роли и эксплуатационные ограничения. Этот этап не объявляет приложение готовым к удалённой промышленной работе.

У аккаунта одно членство в организации; технический администратор имеет отдельный флаг управления аккаунтами. Multi-membership/SSO не входят в текущий интерфейс. Модель GS-006 содержит только название черновика; аудит смены видимости хранит номер и содержимое этой версии. Финансовые вложения и публикация provenance будут реализованы вместе с шаблонами.

Технические источники: [Starlette request limits](https://www.starlette.io/requests/) — max_part_size не ограничивает загружаемый файл, поэтому используется RequestBodyLimitMiddleware и отдельное ограничение чтения файла; [SQLAlchemy FOR UPDATE](https://docs.sqlalchemy.org/en/14/core/selectable.html?highlight=for_update) — SKIP LOCKED для PostgreSQL. API подтверждены установленными версиями и реальными интеграционными тестами.
