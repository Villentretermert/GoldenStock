# GS-010: Извлечение документов и OCR
Статус: DONE (техническое извлечение; реальный эталон остаётся на проверке GS-004). Приоритет: P0. Порядок: 10/24.
Зависимости: GS-004, GS-008.
Этап: 3. GitHub issue: https://github.com/Villentretermert/GoldenStock/issues/10.

## Задача
Разбирать согласованные PDF/PPTX/XLSX; OCR сканов локально; сохранять страницу, таблицу и ячейку.

Уточнение 2026-10-22 (docs/STAGE_2_ANSWERS.md): сканы PDF обязательны сразу, только английский, без перевода; лимит 50 MB. Реальная эталонная разметка GS-004 ещё не готова: технические проверки на синтетических документах не доказывают accuracy 95%. Объём загрузок и целевое время обработки не заданы.

## Результат и критерии приёмки
Сырые таблицы и факты с происхождением, уверенностью и статусом проверки.

## Проверки
Эталонный набор: сканы, объединённые ячейки, отрицательные значения, сноски, пустые значения.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.


## Фактический результат
Реализованы адаптеры PDF/PPTX/XLSX, локальное Tesseract OCR, ограниченный дочерний процесс, сырые результаты с происхождением/уверенностью/статусом unreviewed, API и просмотр. Сценарий и ограничения — docs/EXTRACTION.md.

Проверено 54 теста: полный прогон 52 passed/1 skipped, затем 2 теста изменения прав/lease. Windows OCR отдельно проверено настоящим Tesseract в Docker. PostgreSQL и десять браузерных сценариев проходят. Формулы не исполняются, пропуски не заменяются нулями. Сканы дают слова с координатами; сложные таблицы OCR требуют восстановления и проверки. Реальный эталон не размечен, 95% не заявляется.
