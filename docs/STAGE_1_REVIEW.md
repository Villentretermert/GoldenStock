## Что работает
HTML-прототип: переходы, проверка факта, блокировка модели до проверки, публикация с подтверждением, очередь загрузки, сообщения об экспорте и сравнение моделей. Эти действия меняют только состояние preview.
Python evaluation/score.py: валидация схемы и уникальности, Decimal-допуск, accuracy/precision/coverage, пропуски, abstention, Wilson interval. Никакая LLM ещё не запускалась.

## Проверки
12 unittest проходят. Браузерный smoke: 9 групп сценариев, JavaScript ошибок 0, mobile overflow false. Просмотрены desktop 1280px и mobile 390px. Скриншоты в design/previews (локальные, не Git).
Статически разобраны восемь сценариев доступа/утечек. Это не подтверждает работу ещё не реализованных API и RLS.
Синтетический корпус воспроизводится evaluation/build_starter.py. Он не является независимым тестом качества реальной ИИ.
