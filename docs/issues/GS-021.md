# GS-021: AI Lab и сравнение моделей
Статус: DONE (технический объём). Приоритет: P1. Порядок: 21/24.
Зависимости: GS-004, GS-014, GS-016.
Этап: 6. GitHub issue: https://github.com/Villentretermert/GoldenStock/issues/21.

## Задача
Запускать несколько моделей на одной неизменяемой задаче, размечать ответы и считать стоимость/скорость/качество.

## Результат и критерии приёмки
Experiment/Dataset/Run/Annotation; дедупликация входов и раздельные model runs.

## Проверки
Одинаковые входы/промпты сравнимы; слепая оценка и независимый holdout; версии воспроизводимы.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.


## Фактический результат
Реализованы личные immutable Dataset/Experiment, LabSourceSplit и история LabAnnotation; отдельные AIRun для каждого case/profile. Ровно два закреплённых Qwen, одинаковое evidence, общая последовательная GPU-очередь. Дедупликация, версии prompts/schemas/weights, fail-closed при drift, CSRF/ACL, отмена/повтор и слепая оценка с раскрытием после разметки всех успешных ответов.

Метрики: precision/recall/F1 по всем case, отдельные citation/context accuracy, ручные verdict, время/токены. Ошибки не исключаются из recall. Денежная стоимость неизвестна. Документ нельзя смешивать между development/holdout; использованный holdout нельзя менять или переиспользовать для новых конфигураций. Независимость разметчика и полнота реального корпуса не заявляются.

Проверки: 206 passed / 1 Windows OCR skipped; 10 lab-тестов после уточнений; PostgreSQL concurrency/recovery PASS. Браузер с реальными локальными Qwen прошёл обе задачи/два профиля, формы, blind/reveal и desktop/mobile. Нет JS-ошибок, внешних запросов и переполнения страницы. Тестовая разметка — uncertain, не человеческая приёмка.
