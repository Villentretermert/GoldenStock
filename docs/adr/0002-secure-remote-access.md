# ADR-0002: удалённый доступ к локальному пилоту
2026-10-21. Требование подтверждено: сотрудники подключаются удалённо к этому компьютеру.

Частная VPN-сеть соединяет устройства сотрудников с компьютером-хостом. Reverse proxy принимает только соединения из VPN и направляет их в web/API. Дополнительно обязательны TLS, индивидуальные учётные записи и отзыв сессий. VPN не заменяет tenant/ACL в приложении.

Вариант VPN не выбран. Рассмотреть WireGuard с управлением ключами либо управляемую mesh VPN после проверки условий и доступности сети пользователя. Не открывать RDP, PostgreSQL или inference наружу. Туннели, port forwarding и правила firewall в текущей задаче не создавались.

Приёмка GS-023: доступ с разрешённого устройства; отказ с обычного интернета; отзыв сотрудника; TLS; reconnect; отсутствие широкого доступа ко всему ПК; восстановление после перезагрузки. 15 аккаунтов тестируются отдельно от GPU concurrency.

ПК должен оставаться включённым. Сон Windows, питание и состояние диска описываются в инструкции эксплуатации. До измерений нет гарантии 24/7.
