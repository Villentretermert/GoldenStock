## Повтор записи

Установить `GS_RUNTIME_ROOT` по bundled runtime. Для записи нужны Playwright/Chrome, локальный Docker-стенд и FFmpeg в `.build-overview/media-runtime/imageio_ffmpeg/binaries`. В этой записи использован imageio-ffmpeg 0.6.0 в изолированной build-папке. `GS_DEMO_CPU=1` явно разрешает выбор CPU только для синтетических заданий. Запустить `scripts/record_project_demo.py`, затем `scripts/finalize_project_demo.py`. Существующий MP4 не перезаписывается. Синтетический аккаунт отзывается в finally.
