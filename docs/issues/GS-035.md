# GS-035 — Диапазон сценарной стоимости на первом экране

[GitHub issue #35](https://github.com/Villentretermert/GoldenStock/issues/35).

## GS-035
Приоритет P1. Статус DONE в техническом объёме.

## Основание и порядок
Ответы пользователя от 8 ноября 2026 после GS-025–028. Зависимости GS-019. Выполнять последовательно с учётом контрольной точки после четырёх завершённых задач.

## Результат
Показывать диапазон по сценариям первым, раскрывать базовую оценку, предпосылки, метод и статус проверки. Честно обозначать отсутствие нескольких сценариев.

## Проверки
Проверка сценарных границ, отсутствующих/непригодных сценариев, исторических оценок и мобильного отображения.

## Границы
Реальные эталоны, методика и допуск фонда остаются в GS-001/004/023/024. Цель 10 минут применяется к обновлению готовой модели по всем девяти банковским метрикам. Нативный PPTX пользователь разрешил проверить отдельным примером позднее.
