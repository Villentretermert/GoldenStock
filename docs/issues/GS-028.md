# GS-028 — фрагменты длинного текста для локального ИИ

Статус IN PROGRESS. Приоритет P0. Зависимости GS-010, GS-013/014, GS-025/026. [GitHub issue #28](https://github.com/Villentretermert/GoldenStock/issues/28).

В полном JPMorgan восемь элементов, в HSBC 138 элементов превышают прежние 6000 символов JSON входа. Такие элементы невозможно отправить ИИ целиком. Задача поддерживает GS-004/024 и выполняется после GS-027.

1. Разбивать исходный текст в пределах прежнего лимита, сохранять локатор, индекс элемента, SHA-256 и позиции символов.
2. Показывать точный вход до отправки и после выполнения, давать переход к следующему фрагменту и оригиналу.
3. Получать вход только из приватного завершённого извлечения на сервере. Сохранить идемпотентность, очередь, ACL и старые задачи.
4. Проверить лимиты, Unicode, границы токенов, отсутствие пропусков, браузер и локальный ИИ на синтетике. Обновить инструкцию и подготовить обзор GS-025–028.

Каждый запрос запускает аналитик. Все предложения остаются unreviewed. Полная автоматическая обработка документа, качество 95% и реальная методическая приёмка не входят в техническое закрытие этой задачи. Резервные оригиналы не использовать.
