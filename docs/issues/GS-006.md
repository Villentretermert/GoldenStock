# GS-006: Организации, аккаунты и права
Статус: DONE (2026-10-22, объём локального этапа). Приоритет: P0. Порядок: 6/24.
Зависимости: GS-005.
Этап: 2. GitHub issue: https://github.com/Villentretermert/GoldenStock/issues/6.

## Задача
Вход, 15 аналитиков, личные/общие объекты и минимальная техническая роль управления аккаунтами.

## Результат и критерии приёмки
Проверка организации и прав на каждом объекте; аудит изменения видимости.

## Проверки
Негативные API-тесты между двумя организациями и двумя аналитиками, включая файлы и поиск.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.


## Фактический результат
Созданы организации, аккаунты, сессии с отзывом, вход/выход, техническое управление аккаунтами и метаданные личных/общих черновиков. Tenant задаётся из серверной сессии; администратор не обходит ACL. Смена видимости использует expected revision и сохраняет аудит. Первый администратор и сброс пароля — через локальный интерактивный CLI.

Код: auth.py, accounts.py, admin.py, models.py; миграция 0002. UI: страницы входа, Team и Models на Python/FastAPI. Новое решение вместо кандидата NiceGUI описано в ADR-0003.

Проверки: 15 аккаунтов; два аналитика одного фонда и другой фонд; личное/общее чтение, запрет чужой записи, поиск, CSRF/Origin, истечение/отзыв сессий, HTML escaping, throttling. Проверки чужих файлов и jobs завершены совместно с GS-008. Все 36 тестов этапа проходят, реальный браузер проверил вход/выход и общий черновик.

Ограничения: одно членство у аккаунта; SSO, MFA, RLS и TLS/VPN не реализованы. Общая модель сейчас содержит только название черновика, не финансовые данные/вложения. Для будущих шаблонов потребуется отдельная публикация provenance. Приложение остаётся доступно только локально.
