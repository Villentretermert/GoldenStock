# GoldenStock

Локальное веб-приложение для финансовых аналитиков фонда: документы и публичные источники, проверенные факты и сводки с цитатами.

## Текущий статус

9 ноября 2026: завершена 31 из 36 задач. На первом экране личной оценки показаны [сценарные диапазоны цены акции и стоимости капитала](docs/SCENARIO_RANGES.md), базовая точка, предпосылки и статус проверки. Методы разделены; одиночные, неполные и исторические наборы обозначены явно. Работают [публикации Excel-версий и уведомления](docs/TEMPLATE_PUBLICATIONS.md), сравнение SEC, пакеты PDF, контекст и обмен разметкой. Далее GS-036 — мастер сопоставления книги, затем обязательный обзор. Реальная приёмка GS-001/004/023/024 остаётся открытой; 95% и обновление готовой модели по девяти метрикам за десять минут не подтверждены.

Для ручной разметки подготовлен [корпус трёх зарубежных эмитентов](docs/ISSUER_CORPUS.md). В составе 30 оригиналов, включая шесть резервных документов. Крупные финансовые XLSX показывают заполненные ячейки и границы листов.
Реализованы аккаунты и прикладные права, компании и избранное, приватные оригиналы, извлечение PDF/PPTX/XLSX и OCR, нормализация, ручная проверка фактов, локальные профили Qwen, очередь AI-задач, лексический RAG и SEC-сводки. Числовые утверждения сводки показываются дословно из источников. Работает библиотека версий Excel-шаблонов с явной картой ячеек и очищенными общими копиями. Добавлены частные расчёты на Decimal, три сценария, контрольные равенства и повторное воспроизведение сохранённых входов. Работают банковские DDM/FCFE и P/E/P/B с явными допущениями, чувствительностью и дополнительными пользовательскими показателями.

GS-002–003 и GS-005–022 завершены в заявленном объёме. GS-001/004 остаются REVIEW. Доступны XLSX/PDF/PPTX из личных оценок. AI Lab сравнивает два локальных Qwen на неизменяемых входах: слепая оценка, версии эталонов, защита holdout, precision/recall и контекст. Добавлены проверки SEC по избранному каждые 6 часов и личные уведомления Updates; Сбер/Т-Технологии пока без английского коннектора. Подготовлен профиль частного HTTPS-доступа и проверено зашифрованное резервное восстановление. Подключение фонда и отдельного носителя ожидает полевой приёмки GS-023. Качество 95% не подтверждено. Подробности: [план](docs/PROJECT_PLAN.md), [обзор этапа 5](docs/STAGE_5_REVIEW.md).

Технический пакет GS-024 подготовлен, статус REVIEW. Для приёмки есть сквозной тест пяти компаний, 11 критериев допуска и план года. Реальные качество, методика и полевая эксплуатация остаются открытыми. Актуальный [обзор этапа 6](docs/STAGE_6_REVIEW.md).

GS-025 добавляет [полные PDF до 1 000 страниц](docs/LONG_PDF.md): обработку по 25 страниц, сохранение прогресса, отмену и продолжение после сбоя. Частичные данные доступны только после окончания обработки всего файла. Полный пакет JPMorgan подготовлен для [ручной проверки](docs/JPMORGAN_FIRST_REVIEW.md); техническое извлечение не подтверждает качество ИИ 95%.

7 ноября 2026. GS-028 добавляет [предпросмотр и фрагменты длинного текста для локального ИИ](docs/AI_EVIDENCE_WINDOWS.md). Завершены 24 из 28 задач. [Обзор GS-025–028 и 12 вопросов](docs/STAGE_7_REVIEW.md) завершает контрольную точку. Реальная разметка и приёмка GS-001/004/023/024 остаются открытыми.

## Запуск
Нужны Python 3.12–3.14 для bootstrap и Docker Engine с Compose. Из корня проекта:
```sh
python scripts/bootstrap.py --up
```
Первый администратор создаётся интерактивно:
```sh
docker compose exec web python -m goldenstock.admin create-admin --login owner
```
Открыть http://127.0.0.1:8080 (или порт GS_WEB_PORT из локального .env). Готового пользовательского пароля нет. На Windows с Docker внутри WSL команды выполняются через `wsl -d Ubuntu --`.

GPU, загрузка весов и локальные профили: [LOCAL_AI.md](docs/LOCAL_AI.md). SEC требует собственного контакта `GS_SEC_CONTACT` в локальном `.env`.
