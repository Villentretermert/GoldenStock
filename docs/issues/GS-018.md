# GS-018: Детерминированный расчётный движок
Статус: DONE в техническом объёме. Приоритет: P0. Порядок: 18/24.
Зависимости: GS-004, GS-017.
Этап: 5. GitHub issue: https://github.com/Villentretermert/GoldenStock/issues/18.

## Задача
Пересчёт допустимых формул вне LLM, Decimal/округления, снимок входов, сценарии и воспроизводимость.

## Результат и критерии приёмки
Численные результаты с версией шаблона/движка и контрольными сверками.

## Проверки
Сравнение с эталонными книгами; деление на ноль, пустые входы, округление, несходящиеся балансы.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.


## Фактический результат
Реализованы Decimal-движок gs018-v1, миграция 0012 и CalculationRun; API создания/чтения/replay; UI сценариев и сверок. Входы — подтверждённые ручные предпосылки либо совместимые факты из актуального личного проверенного снимка. Сохранены автор, источники, карта/версия шаблона, версия движка и хеши. Численные ошибки и несошедшиеся равенства блокируют результат.

Пояснительная записка, сценарий использования, архитектура и ограничения: [CALCULATIONS.md](../CALCULATIONS.md).

Проверки: 161 passed / 1 Windows OCR skipped в полном прогоне; 55 целевых passed после уточнения численной политики и выбора фактов. PostgreSQL: миграция, параллельная идемпотентность, атомарная проверка снимка против изменения решения, совместимость порядка блокировок с sharing, replay и отказ на устаревшем наборе — PASS. Браузер: 22 сценария, в том числе три расчётных сценария, replay и mobile; нет JS-ошибок, внешних запросов, переполнения страницы. Desktop/mobile просмотрены визуально.

Синтетический прогноз сверён с известными ответами и пересчитанным кэшем XLSX GS-017. Реальные независимые книги и accuracy 95% не подтверждены: GS-004 остаётся REVIEW. Результат арифметики не является утверждённой оценкой компании. Следующая GS-019, обзор после GS-020.
