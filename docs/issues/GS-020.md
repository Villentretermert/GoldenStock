# GS-020: Экспорт XLSX, PDF и PPTX
Статус: DONE (технический объём). Приоритет: P0. Порядок: 20/24.
Зависимости: GS-016, GS-019.
Этап: 5. GitHub issue: https://github.com/Villentretermert/GoldenStock/issues/20.

## Задача
Собрать модель, отчёт и презентацию из одного снимка расчёта с источниками и статусом проверки.

## Результат и критерии приёмки
Три скачиваемых формата; версия и дата на каждом; визуально проверенные страницы/слайды.

## Проверки
Числа совпадают во всех форматах; XLSX пересчитывается, PDF/PPTX без обрезок.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.
После завершения обязательны презентация этапа и минимум 10 вопросов до следующей задачи.

## Фактический результат
Реализованы три приватных скачивания из ValuationRun, проверка целостности и replay, маркировка исторических данных, Excel-формулы со связями Calc → Val → Summary и пересчитываемой чувствительностью, PDF/PPTX с источниками. См. [EXPORTS.md](../EXPORTS.md).

Проверки: полный прогон 197 passed + 1 Windows OCR skipped; после уточнений 9 экспортных passed. Независимый пересчёт четырёх методов, трёх сценариев, исходной прибыли/котировки/акций и границ пройден. PostgreSQL PASS, браузер 31 сценарий PASS. Рендеры проверены; MS Office desktop не запускался. Реальная accuracy 95% не подтверждена.

Контрольная точка: [STAGE_5_REVIEW.md](../STAGE_5_REVIEW.md), локальная презентация, 12 вопросов. До ответов GS-021 не начинать.
