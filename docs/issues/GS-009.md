# GS-009: Реестр публичных источников
Статус: DONE (реестр; сбор документов не входит). Приоритет: P0. Порядок: 9/24.
Зависимости: GS-007, GS-008.
Этап: 3. GitHub issue: https://github.com/Villentretermert/GoldenStock/issues/9.

## Задача
Проверить англоязычные раскрытия пяти эмитентов, доступность, условия использования и даты.

## Результат и критерии приёмки
Каталог разрешённых IR/регуляторных источников; публичные данные отделены от приватных.

## Проверки
Источник недоступен/устарел, совпадают имена компаний, отсутствует английская версия.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.


## Фактический результат
Созданы девять записей официальных источников для пяти согласованных эмитентов, read-only API и страница Sources. Метаданные версионированы в sources.py и отделены от приватных документов. Миграция 0005 уточняет названия/идентификаторы без смены ID. Подробные доказательства и условия: docs/PUBLIC_SOURCES.md.

Английское покрытие Сбербанка/Т-Технологий не подтверждено; отражён пробел без перевода. Доступность, срок проверки, английский язык и загрузка данных разделены. Полный корпус не собран; автоматический сбор отключён для всех записей, ограничения прав отмечены явно. Следующие GS-010/014/022 отвечают за извлечение, коннекторы и мониторинг.

Проверки: 45 pytest, PostgreSQL (миграции, конкурентность, восстановление очереди), девять браузерных сценариев, desktop/mobile без переполнения и ошибок JS. Скриншоты локально: design/previews/sources-desktop.png и sources-mobile.png.
