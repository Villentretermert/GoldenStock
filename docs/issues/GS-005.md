## Задача
Создать backend, Python-first UI, worker, приватный inference endpoint и Compose для разработки.

## Результат и критерии приёмки
Запуск одной командой, миграции, healthchecks, CI и пример переменных без секретов.

## Проверки
Smoke запуск чистого окружения, API доступен, БД и ИИ не опубликованы наружу.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.


## Фактический результат
Реализованы FastAPI API, NiceGUI UI, PostgreSQL, Alembic и heartbeat worker. Docker Compose запускается через scripts/bootstrap.py; локальный пароль генерируется без вывода и не перезаписывается. Опциональная Ollama работает без загруженных весов. Инструкция: docs/RUN_LOCAL.md.

Проверки: 24 теста прошли (12 foundation и 12 evaluation), pip check успешен. Контейнеры собраны с Python 3.14.7 в существующем Ubuntu WSL2; db, worker, web, inference healthy. Миграция повторно выполнена без ошибки. Реальный браузер на 127.0.0.1:8081: readiness 200, database/worker ready, inference no_model_loaded; ошибок JS и внешних запросов нет, мобильного переполнения нет. Скриншоты: design/previews/app-desktop.png и app-mobile.png (локальные артефакты).

Сеть: только web публикует 127.0.0.1:8081. Web подключён к ingress и private; остальные сервисы только к internal private, без host ports. Одной internal-сети оказалось недостаточно для публикации порта в установленном Docker; исправление проверено браузером.

CI подготовлен, но GitHub Actions ещё не запускался: публикация исходников отдельно не разрешена. Один warning TestClient о будущем переходе с httpx на httpx2; тесты проходят. Учётные записи, финансовые операции, бизнес-очередь, GPU inference и удалённый доступ не входят в завершённый объём. Следующая задача — GS-006.
