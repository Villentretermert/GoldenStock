# Предложения для пилота
Обновление 2026-10-21: пилот запускается на существующем компьютере. Ниже облачный бюджет сохранён как исторический вариант, он больше не является бюджетом пилота. Для локального пилота учитывать электричество, резервный диск, VPN при необходимости и эксплуатацию; без тарифа электричества и выбранного носителя достоверная сумма не установлена.

Дата проверки источников: 2026-10-19. Предложения не утверждены пользователем.

## Три зарубежные компании
- JPMorgan Chase — кандидат крупного банковского бизнеса; [официальная годовая отчётность](https://www.jpmorganchase.com/ir/annual-report/2025).
- HSBC — кандидат международного банка; [англоязычные годовые отчёты](https://www.hsbc.com/investors/results-and-announcements/annual-report).
- Nu Holdings — кандидат цифрового банковского бизнеса; доступность и состав актуальных раскрытий необходимо проверить в GS-009.

Это предложение по составу тестового корпуса, не инвестиционная рекомендация и не утверждение о сопоставимости всех мультипликаторов. Для каждого эмитента нужны отдельные определения активных клиентов и дохода на клиента; отсутствующие Retention/LTV не выдумывать.

## Облако и предварительный бюджет
Кандидат для проверки — выделенный GPU-сервер в ЕС у Hetzner плюс CPU-приложение и независимые резервные копии. Провайдера не заказывать до benchmark, проверки региона, договора и доступности.
[Официальная линейка GPU](https://www.hetzner.com/dedicated-rootserver/matrix-gpu/) и [изменения цен](https://docs.hetzner.com/general/infrastructure-and-availability/price-adjustment/) подтверждают наличие предложений; конкретный тариф не зафиксирован.

Ниже инженерный резерв бюджета, а не коммерческая котировка:
| Статья | EUR/месяц |
|---|---:|
| Один локальный GPU inference узел, резерв диапазона | 300–1200 |
| CPU/API/БД/worker | 80–200 |
| Файлы и независимые резервные копии | 30–100 |
| Мониторинг, сеть и прочее | 30–100 |
| Подытог | 440–1600 |
| Резерв 25% | 110–400 |
| Итого | 550–2000 |

На 12 месяцев: EUR 6600–24000 только инфраструктура. Не включены разработка, эксплуатационная работа людей, НДС, разовые setup fees, платные данные и дополнительные GPU для одновременного сравнения моделей. Бессрочное хранение увеличивает затраты со временем.
Размер модели, VRAM, скорость OCR и одновременные задания могут вывести стоимость за диапазон. GS-013 измеряет нагрузку; GS-023 превращает диапазон в проверенную смету. Бюджет разработки оценить после GS-001–004, не смешивать его с ценой облака.
