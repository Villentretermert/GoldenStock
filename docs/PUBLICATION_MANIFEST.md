# Пакет публичного репозитория

2026-10-27: подготовлен по поручению пользователя. Назначение: https://github.com/Villentretermert/GoldenStock, main.

Публикуется актуальный снимок исходников, тестов, Docker, документации и синтетических данных. Исторические локальные коммиты не передаются. .env, пользовательские файлы и базы, веса, исторические исследования и PPTX исключены. Локальная инвентаризация компьютера заменена общей инструкцией. Секретные шаблоны проверены до отправки.
