# GS-016: ИИ-сводка по кнопке
Статус: DONE (локальный технический объём). Приоритет: P0. Порядок: 16/24.
Зависимости: GS-007, GS-012, GS-015.
Этап: 4. GitHub issue: https://github.com/Villentretermert/GoldenStock/issues/16.

## Задача
Уточнение этапа 3 (2026-10-23): допустимое ожидание сводки до 5 минут. Это целевое требование, ещё не результат измерения. Нагрузка 45 документов/день; первый полный сценарий можно проверить на JPMorgan, HSBC и Nu. Английские пробелы российских эмитентов сохранять.

Запросить публичные источники, собрать сводку компании и показать расхождения/пробелы.

## Результат и критерии приёмки
Сводка с датой среза, ссылками на доказательства и явными неопределённостями.

## Проверки
Каждое существенное утверждение проверяется; отсутствие данных не превращается в выдуманную цифру.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.
После завершения обязательны презентация этапа и минимум 10 вопросов до следующей задачи.

## Фактический результат
2026-10-24: завершён реальный сетевой и браузерный сценарий SEC для JPMorgan, HSBC и Nu. Личная сводка была проверена ранее. 18 браузерных сценариев прошли, включая три публичных сводки; оригинал JSON доступен для скачивания. Исправлена обнаруженная ошибка числового пересказа: summary-v3-extractive выводит полное выбранное свидетельство вместо сгенерированного утверждения. 13 целевых тестов проходят. Пробелы ИИ требуют ручной проверки, полное покрытие периодов и accuracy 95% не подтверждены.
Обзор, презентация и вопросы: docs/STAGE_4_REVIEW.md. До GS-017 дождаться ответов.
