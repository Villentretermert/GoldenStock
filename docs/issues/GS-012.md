# GS-012: Рабочее место проверки аналитика
Статус: DONE (локальный объём входных данных). Приоритет: P0. Порядок: 12/24.
Зависимости: GS-003, GS-011.
Этап: 3. GitHub issue: https://github.com/Villentretermert/GoldenStock/issues/12.

## Задача
Основа GS-011 готова: docs/NORMALIZATION.md, append-only facts, supersedes, API /conflicts. Реализовать шлюз утверждения с блокерами profit/equity; не считать наличие поля blocker уже работающим запретом. Явные решения аналитика и снимки входов должны учитывать версии фактов/политики и изменение контекста.

Уточнение 2026-10-22: ручную проверку выполняет один аналитик; независимой двойной разметки нет. Расхождения прибыли/капитала блокируют утверждение. После GS-012 обязательны презентация, минимум 10 вопросов и ожидание ответов.

Показывать источник рядом с фактом, исправления, выборочное подтверждение и обязательные блокировки критических ошибок.

## Результат и критерии приёмки
Аудит ручных решений, сохранённые наборы проверенных входных данных.

## Проверки
Исправление создаёт версию; конфликт критического входа блокирует финальный статус оценки.

## Пояснительная записка
При выполнении описать решение, изменённые файлы/сущности, ограничения и доказательства проверок. Обновить CHANGELOG.md и статус задачи. Прочитать PROJECT_RULES.md перед началом.
После завершения обязательны презентация этапа и минимум 10 вопросов до следующей задачи.

## Фактический результат
Реализованы FactReview, InputSnapshot, миграция 0008, приватный API и Python-экран источника рядом с фактом. Решения добавляются в историю; исправление требует новой проверки. Сервер запрещает сохранение неподтверждённых входов и конфликтов прибыли/капитала. Изменение фактов/решений делает снимок устаревшим. Расчёт и финальный статус оценки ещё не существуют; будущий движок обязан применять этот шлюз.

89 тестов проходят, 1 Windows OCR skipped и отдельно проверен в Docker. Обзор GS-009–012: docs/STAGE_3_REVIEW.md и локальный deliverables/GoldenStock-Stage-3-final.pptx (8 слайдов). До GS-013 ждём ответы на 12 вопросов; 95% пока не подтверждены.
