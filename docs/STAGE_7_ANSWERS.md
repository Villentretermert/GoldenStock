# Ответы после обзора GS-025–028

8 ноября 2026 получены все 12 ответов. Контрольная точка пройдена. Следующая задача GS-029, пакетный запуск ИИ по выбранным PDF-страницам. Следующий обязательный обзор после четырёх завершённых задач, планово GS-029–032.

| № | Ответ пользователя | Решение и задача |
|---|---|---|
| 1 | Пакетный запуск ИИ по выбранным страницам | Первый приоритет GS-029 |
| 2 | К обновлению готовой модели | Цель десяти минут относится к обновлению готовой модели, первоначальное построение измеряем отдельно |
| 3 | Все девять метрик | В замер входят прибыль, капитал, активы, ROE, ROA, NIM, cost/income, NPL и стоимость риска |
| 4 | Выбирать раздел по названию | GS-030, раздел должен иметь проверяемые страницы оригинала |
| 5 | Автоматически, с отдельной ссылкой на источник | GS-030, соседний заголовок/контекст сохраняет собственный локатор |
| 6 | Предлагать выполнение на CPU | GS-031, при недостатке GPU для резерва 3 GiB предлагать CPU, переход требует выбора аналитика |
| 7 | Нужен также экспорт и импорт таблицы | GS-032, обмен ручной разметкой с версиями и валидацией |
| 8 | Проверить отдельным примером позднее | Нативный PPTX временно исключён из обязательного реального корпуса до допуска пилота, проверка отдельным пользовательским примером остаётся открытой |
| 9 | Сравнение новых и прежних значений | GS-033, в Updates сначала разница SEC с источниками и контекстом |
| 10 | Всем её читателям | GS-034, уведомления читателям при публикации общей версии автором |
| 11 | Диапазон стоимости по сценариям | GS-035, диапазон первым, базовая оценка и предпосылки доступны |
| 12 | Мастер сопоставления строк произвольной книги | GS-036, приоритет мастера перед требованием вручную адаптировать книгу к контракту |

Десять минут включают очередь, обработку, ручную проверку всех включённых фактов, пересчёт и экспорт. Начальные данные для обновления и готовая модель должны быть зафиксированы в протоколе. Достигнутое время пока не измерено. Прибыль акционеров, полный капитал с NCI, учёт округления и пороги accuracy/precision/coverage по 95% сохраняются.

Перенос PPTX не означает приёмку формата или уменьшение объёма корпуса 30/500 с holdout минимум 6/100. Остальные требования качества, английского языка и официальных источников сохраняются. Предлагаемый порядок после GS-032 требует очередного обзора до GS-033.

Ручную сверку JPMorgan пользователь выполнит в кабинете позже. Реальные факты, методика, Tailscale фонда, носитель и перезагрузка остаются открытыми. Разработчик не заменяет подписи аналитика автоматическими решениями.
