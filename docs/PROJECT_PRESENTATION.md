## Что доказывает демонстрация

Запись сделана в отдельной синтетической организации. Девять учебных фактов, снимок, расчёт, четыре метода оценки и карта Excel подготовлены перед записью. В кадре выполнены публикация очищенной структуры, replay расчёта и скачивание XLSX/PDF/PPTX. Тестовый аккаунт отозван после записи; реальные документы, gold-факты и подписи пользователя не менялись.

В записанном запуске Qwen3 1.7B на CPU сервер отклонил ответ с `unsupported_evidence`; это показано в главе 09. GPU не был допущен при требуемом резерве. Этот отказ не скрыт и не считается успешным извлечением. Слайд 12 содержит отдельно помеченный сохранённый результат предыдущей синтетической проверки Qwen3 4B. Экран сравнения SEC также относится к синтетическому тесту. Видео не является замером десятиминутного обновления или доказательством accuracy.

Функциональная база обзора — `0a389bb9e30f091443a422ab2afcffdf75d96720`, [CI 45416508431](https://github.com/Villentretermert/GoldenStock/actions/runs/45416508431). Приложение ради записи не изменялось. 32 из 36 задач завершены технически; GS-001/004/023/024 остаются REVIEW. 3 из 11 критериев допуска пройдены технически, восемь pending, реальная приёмка NO-GO.

При проверке кода выявлено отдельное замечание: `lab_scoring.validate_reference` допускает число-подстроку цитаты, например `12` в `120`. Защита ответа провайдера уже строже, но эталоны AI Lab требуют собственного исправления и версии. Замечание записано в [GS-004](issues/GS-004.md) и GitHub issue 4; в рамках создания презентации оно не исправлялось.

## Пересборка

Указать `GS_RUNTIME_ROOT` на установленный bundled runtime и `GS_DECK_NAME` на новое имя PPTX. Генератор использует `@oai/artifact-tool` и штатный финализатор презентаций. Нужны локальные изображения из `design/previews/`; из публичного checkout без этих изображений получится только текстовое сопровождение, готовый PPTX не воспроизводится автоматически.

Запустить `scripts/build_project_overview.mjs` через Node из runtime. Рендер выполняется отдельным процессом `scripts/render_project_overview.mjs`; PDF создаёт `scripts/build_project_pdf.py` через ReportLab и проверяет PDFium. Существующий итоговый файл не перезаписывается. Для словаря сущностей достаточно `scripts/document_schema.py`: он читает SQLAlchemy metadata, не пользовательскую БД. Для видео следовать [инструкции записи](PROJECT_DEMO.md), затем выполнить `scripts/check_project_demo.cjs`.
